# Finding Your Spotlight (FYS)

A high-performance, conversion-focused personal brand platform and admin dashboard built for **Jennis Williamson**, Purpose and Career Mentor for Creatives.

The project replaces an outdated WordPress/Elementor site with a modern Next.js application paired with a unified Supabase backend. It features a "Cinematic Noir" dark-mode visual experience, an inline eBook digital storefront powered by Yoco, and a client management portal.

---

## 🌟 Key Features

### Frontend Website
* **Cinematic Noir Aesthetic:** Deep obsidian tones (`#0a0a0a`), high typographic contrast using the Geist Sans font family, and subtle lighting accents.
* **Conversion-Driven Single Page Layout:** Streamlined architecture focused on converting visitors into consultation bookings.
* **Lean Consultation Intake Form:** Ultra-simple form capturing client name, email, phone, session topic, and preferred meeting format (Online vs. In Person).
* **Digital eBook Storefront:** Seamless checkout for Jennis's digital publication catalog with instant PDF access upon successful payment.
* **POPIA Compliant:** Embedded Privacy Policy and Terms of Service tailored for South African data privacy legislation.

### Backend & Admin Dashboard (`/admin`)
* **Consultation Request Pipeline:** Status tracking (`Pending`, `Contacted`, `Confirmed`, `Archived`) for all incoming booking leads with direct WhatsApp and email actions.
* **eBook Catalog Management (CRUD):** Dedicated admin panel for editing book details, updating ZAR prices, uploading cover images, and publishing new titles.
* **Sales & Revenue Analytics:** Automated order tracking and revenue reports synced via Yoco payment
